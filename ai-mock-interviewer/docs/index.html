AI Mock Interviewer

Open-source interview practice · Runs on your computer

Practice technical interviews before the real one.

Voice and typed mock interviews for DevOps, SRE, Cloud, Platform Engineering, and MLOps. The built-in question bank and template feedback work offline. Local or cloud AI feedback is optional.

Use it

This page is the public entry point. The interview app is a Node.js server, so install it locally and open it on your machine. You need Node.js 22 and npm.

git clone https://github.com/iarsingh/ai-mock-interviewer.git
cd ai-mock-interviewer
npm ci
cp .env.example .env
npm run start:offline

Then open http://127.0.0.1:3030, create an account, and start a practice topic. Typed answers work without a microphone. On Windows PowerShell, use Copy-Item .env.example .env instead of cp.

What you can practice

  • Topic practice across Kubernetes, cloud, Terraform, CI/CD, Python, SRE, and related areas.
  • Fixed mock interview sets and a multi-day practice plan.
  • Job-description practice from pasted text or an uploaded file.
  • Optional feedback from local Ollama, OpenAI, or Anthropic when you configure it.

Before you rely on an answer

Practice material. Verify it before you rely on it.

Answers, explanations, code examples, and AI feedback may be incorrect, incomplete, or outdated. Check official documentation for your technology version, and try commands in a safe test environment. This project is not a verified assessment of interview readiness.

Privacy

Offline mode does not call a configured cloud model. If you enable a cloud provider, the relevant prompt and answer are sent to that provider. Browser speech recognition can also send audio to the browser vendor. Do not put secrets, résumés, or confidential interview material into a public demo.
