3. Can we use a list as a dictionary key? Why not?

Answer:

data = {[1, 2]: "value"}

A tuple can be used if its elements are also hashable:

data = {(1, 2): "value"}

4. What is shallow copy and deep copy?

Shallow copy: Creates a new outer object but nested objects are still shared.

Deep copy: Recursively creates independent copies of nested objects.

import copy
shallow = copy.copy(original)
deep = copy.deepcopy(original)

5. What are decorators?

A decorator modifies or extends the behavior of a function/class without changing its original code.

def logger(func):
    def wrapper():
        print("Before")
        func()
    return wrapper
@logger
def deploy():
    print("Deploying")

Common uses: logging, authentication, authorization, retries, timing, caching.

6. What are generators?

Generators produce values one at a time using yield, rather than storing all values in memory.

def numbers():
    for i in range(5):

They are particularly useful for large files, datasets, and streams.

It ensures the resource is properly released even if an exception occurs.

Internally, context managers commonly use:

__enter__()
__exit__()
