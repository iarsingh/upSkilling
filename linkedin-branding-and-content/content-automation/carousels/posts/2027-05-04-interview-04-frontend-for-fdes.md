Frontend questions for FDEs.
React, Next.js, forms, tables and streaming AI responses.

FDEs build the screen the operator actually uses. You do not need to be a design engineer, but you will be asked how you build forms, data tables and a chat UI that streams. Here is what I would prepare.

Swipe the carousel 👉
1. Questions and short answers
2. Streaming an LLM answer
3. Operator UI
4. How to answer
5. Practise these

The takeaway: Build for the operator's workflow, not for the demo.

What makes an internal AI tool feel trustworthy to operators?

Or just reply 1, 2 or 3: which is hardest to get your team to do?
1️⃣ Validate twice: client and server
2️⃣ Page large tables on the server
3️⃣ Stream, allow stop, show sources
