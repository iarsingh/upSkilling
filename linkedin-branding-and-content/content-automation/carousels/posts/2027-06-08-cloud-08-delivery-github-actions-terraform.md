Ship to any cloud from one pipeline.
Docker, GitHub Actions, Terraform and Kubernetes, without stored keys.

The delivery path is where multi-cloud gets real. One image, one pipeline, and a Terraform module per cloud. Here is the setup I use to deploy into AWS, GCP or Azure with short-lived credentials only.

Swipe the carousel 👉
1. Build once, promote
2. Keyless auth from Actions
3. Terraform per cloud
4. Pipeline hardening

The takeaway: Promote the same image. Change only the cloud edge.
