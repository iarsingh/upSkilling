AI TRANSFORMATION PLAYBOOK#01

Chat window vs production system

Chat window
  • Answers a person
  • Failure is a bad answer
  • Borrows the user's session
  • Ends when the tab closes
Agent
  • Acts for a process
  • Failure is a bad write
  • Holds its own credentials
  • Runs while you sleep

AI TRANSFORMATION PLAYBOOK#01

Three gates before any model choice

  1. 01
    Owner
    A named team that gets paged when the agent misbehaves.
  2. 02
    Rollback
    A tested way to undo what the agent changed.
  3. 03
    Blast radius
    Which systems, data, spend and users it can touch, written down.

AI TRANSFORMATION PLAYBOOK#01

What it inherits from platform engineering

  1. 01
    Versioning
    Model, prompt and tool set pinned together, like an image tag.
  2. 02
    Pipeline
    Changes ship through review and CI, not a settings page.
  3. 03
    SLOs
    Task success rate, latency, cost per run.
  4. 04
    On-call
    A runbook and a kill switch before the first real user.
