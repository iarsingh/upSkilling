AI TRANSFORMATION PLAYBOOK#06

Would not ship — access

  1. 01
    Personal cloud credentials
    Agent actions must not look like mine.
  2. 02
    Apply without GitOps
    No Terraform or kubectl outside the pipeline.
  3. 03
    No tool trace
    If I can't see what it called, it didn't happen safely.

AI TRANSFORMATION PLAYBOOK#06

Would not ship — behaviour

  1. 01
    No written blast radius
    Unknown scope is unlimited scope.
  2. 02
    Retrieval treated as fact
    Snippets without citations become confident errors.
  3. 03
    Auto-paging on first incidents
    A human confirms before waking someone up.
  4. 04
    Data leaving its region
    Residency rules apply to prompts too.

Agent production-readiness check

  • ✓Own workload identity
  • ✓Least-privilege tool scopes
  • ✓Named owner and on-call
  • ✓Written blast radius
  • ✓Tested rollback
  • ✓Eval suite in CI
  • ✓Changes ship via GitOps

  • ✓Human gate for irreversible actions
  • ✓Kill switch

AI TRANSFORMATION PLAYBOOK#06
Key takeaway

Treat agents like production software.

  • Grant only the autonomy you could defend on a bridge call
  • Start read-only, earn Propose, rarely Act
  • Label labs as labs
