# Archived LinkedIn content

This folder contains scheduled content moved out of the active publishing flow
from 2026-08-03 onward so the main calendar can focus on AI, LLM, machine
learning, MLOps, and data science.

- `posts/` contains archived Markdown drafts.
- `assets/` contains each draft's matching PNG, SVG, or doodle image when one
  was generated.
- `content-calendar-entries.json` preserves the removed calendar records.

Run `node scripts/archive-non-ai-content.js YYYY-MM-DD` to repeat the cleanup
for a later cutoff date.
